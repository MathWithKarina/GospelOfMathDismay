# Русский

## Что это?

**Gospel Of Math Dismay (GoMD)** — локальная студия для озвучивания математических текстов. Проект создан для тех, кому нужно превращать формулы, математические выражения и обычный текст в речь.

Это первая публичная версия проекта. GoMD продолжает развиваться, поэтому пока не все функции работают корректно.

## Возможности

- Озвучивание текста.
- Инструменты для работы с математическим текстом.
- Дополнительные функции обработки и подготовки аудио.
- Локально ориентированная архитектура приложения.

Некоторые возможности могут быть экспериментальными, частично реализованными или ещё находиться в разработке.

## Как запустить?

### Вариант 1. Установщик Windows

1. Скачай [GospelOfMathDismay-Setup.exe](https://github.com/MathWithKarina/GospelOfMathDismay/releases/download/v0.1.0/GospelOfMathDismay-Setup.exe).
2. Запусти установщик.
3. Следуй инструкциям мастера установки.
4. Запусти GoMD из меню «Пуск» или с рабочего стола, если создала ярлык.

### Вариант 2. Portable

1. Скачай [GospelOfMathDismay-portable.zip](https://github.com/MathWithKarina/GospelOfMathDismay/releases/download/v0.1.0/GospelOfMathDismay-portable.zip).
2. Распакуй архив целиком в удобную папку.
3. Запусти `GospelOfMathDismay.exe`.

Не перемещай EXE отдельно от остальных файлов сборки.

### Вариант 3. Исходный код

1. Скачай [GospelOfMathDismay-src.zip](https://github.com/MathWithKarina/GospelOfMathDismay/releases/download/v0.1.0/GospelOfMathDismay-src.zip).
2. Распакуй архив.
3. Установи подходящую версию Python в соответствии с требованиями проекта.
4. Запусти `install_windows.bat`.
5. После завершения установки запусти `run_windows.bat`.

Если запускаешь проект не на Windows, дальнейшие действия, надеюсь, разберёшь самостоятельно. 🙂

## Важные замечания

- Доступность синтеза речи зависит от выбранного движка, голосовой модели и необходимых компонентов.

# English

## What is GoMD?

**Gospel Of Math Dismay (GoMD)** is a local-first studio for converting mathematical text and ordinary text into speech.

This is the project's first public release. GoMD is still under development, so some features may be incomplete or may not work correctly.

## Features

- Text-to-speech.
- Tools for working with mathematical text.
- Additional audio preparation and processing features.
- A locally oriented application architecture.

Some features are experimental, partially implemented, or still in development.

## How to run

### Option 1. Windows installer

1. Download [GospelOfMathDismay-Setup.exe](https://github.com/MathWithKarina/GospelOfMathDismay/releases/download/v0.1.0/GospelOfMathDismay-Setup.exe).
2. Run the installer.
3. Follow the setup wizard.
4. Launch GoMD from the Start menu or from your desktop if you created a shortcut.

### Option 2. Portable version

1. Download [GospelOfMathDismay-portable.zip](https://github.com/MathWithKarina/GospelOfMathDismay/releases/download/v0.1.0/GospelOfMathDismay-portable.zip).
2. Extract the entire archive to a convenient folder.
3. Run `GospelOfMathDismay.exe`.

Do not move the executable away from the other files in the distribution folder.

### Option 3. Source code

1. Download [GospelOfMathDismay-src.zip](https://github.com/MathWithKarina/GospelOfMathDismay/releases/download/v0.1.0/GospelOfMathDismay-src.zip).
2. Extract the archive.
3. Install a suitable Python version according to the project's requirements.
4. Run `install_windows.bat`.
5. Once installation finishes, run `run_windows.bat`.

If you're running the project on a non-Windows system, I hope you can figure out the rest yourself. 🙂

## Important notes

- Version `0.1.0` is an early release, not a finished product.
- Some features may be incomplete or may not work as intended.
- Text-to-speech availability depends on the selected engine, voice model, and required components.
- Third-party libraries, engines, and voice models have their own licenses. Check the terms of each component before using it commercially.
